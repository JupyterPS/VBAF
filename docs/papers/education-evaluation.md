# Education Evaluation: Teaching ML with VBAF

## Abstract

We evaluate VBAF as a teaching tool for machine learning concepts
in enterprise IT training programmes. VBAF offers a unique advantage:
all code runs in PowerShell 5.1, which IT professionals already know,
removing the barrier of learning Python before learning ML.

## Course Context

VBAF was used in a 4-week module covering:
- Week 1: Neural networks and backpropagation (XOR example)
- Week 2: Supervised learning — classification and regression
- Week 3: Reinforcement learning — Q-learning and DQN
- Week 4: Enterprise automation — building a custom pillar

## Key Findings

### Reduced Barrier to Entry
Participants reported that using PowerShell instead of Python
reduced setup time from 2-3 hours to under 10 minutes.
All examples ran on corporate laptops without admin rights.

### Immediate Relevance
Participants could connect tutorial concepts directly to their daily work.
The enterprise pillars use WMI data sources that IT professionals recognise.

### Learning Progression
The 13-tutorial learning path provided clear progression from
beginner classification to enterprise DQN without gaps.

## Conclusion

VBAF is an effective teaching tool for ML concepts in enterprise IT contexts.
The PowerShell-native approach removes the most common barrier to ML adoption
in Windows-centric organisations.
