## Quick start for contributors

1. Fork the repo on GitHub
2. Clone locally and run \. .\VBAF.LoadAll.ps1\
3. Make changes in a feature branch
4. Run the module's \Test-VBAF<Module>\ smoke test
5. Submit a pull request with a clear description

## Before submitting

- All PS 5.1 coding standards followed (see \coding-standards.md\)
- Smoke test passes with expected loss / accuracy
- Comment-based help updated for any new functions
