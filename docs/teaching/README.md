# Teaching Materials

Course materials for teaching machine learning and enterprise automation
using VBAF in IT training programmes.

## Contents

| File | Description |
|------|-------------|
| [course-outline.md](course-outline.md) | 4-week course structure |
| [semester-plan.md](semester-plan.md) | 12-week semester plan |
| [exam-questions.md](exam-questions.md) | Assessment questions |

## Target Audience

IT professionals with PowerShell experience who want to learn:
- Machine learning fundamentals
- Reinforcement learning concepts
- Enterprise automation with AI agents

## Prerequisites

- PowerShell 5.1 experience
- Basic understanding of Windows administration
- No Python or prior ML knowledge required
